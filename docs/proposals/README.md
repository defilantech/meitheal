# Proposals

These design proposals were written while Meitheal was Foreman, a part of
LLMKube, and came to this repository with the code's history. They keep the
names of that time: the API group `foreman.llmkube.dev`, the `foreman-agent`
and `foreman-operator` binaries, the `llmkube foreman` commands, and paths
such as `pkg/foreman/agent`.

The current names are the API group `meitheal.dev`, the `meitheal-agent` and
`meitheal-operator` binaries, the `meitheal` CLI, and the flattened layout
(`pkg/agent`, `internal/controller`, `api/v1alpha1`). Issue and pull request
numbers in these documents refer to defilantech/LLMKube.
